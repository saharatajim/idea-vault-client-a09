## 📌 About Project

IdeaVault is a startup idea-sharing platform where users can submit innovative ideas, explore ideas from other users, and interact through comments and discussions.

## ✨ Features

* User Authentication (Email/Password & Google Login)
* Add New Startup Ideas
* Update and Delete Own Ideas
* View Detailed Idea Information
* Comment, Edit, and Delete Comments
* Search Ideas by Title
* Filter Ideas by Category
* JWT Protected Routes
* Dark & Light Theme
* Responsive Design for All Devices

## 🛠️ Technologies Used

### Frontend

* React.js
* React Router DOM
* Tailwind CSS
* ShadCN UI
* Better Auth
* React Toastify

### Backend

* Node.js
* Express.js
* MongoDB
* JWT
* CORS
